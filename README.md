# disagg-ai-eval

Replication code and data for *Prediction-Powered Smoothing and Validation for Disaggregated AI Evaluation* (Kawano, Li and Parker, 2026).

How can we reliably evaluate AI systems across many small domains when human labels are scarce? This paper connects disaggregated AI evaluation with survey sampling: combining model predictions, limited human labels, and information across related domains to improve estimates and quantify uncertainty. The experiments cover LLM benchmarking with Open LLM Leaderboard data and human–AI conversations from PRISM.

The code implements direct, PPI, and GREG estimates; Fay–Herriot and taxonomy smoothing; and design-based cross-validation with covariance-based debiasing.

This release includes the analysis scripts, tests, benchmark matrices, saved judge scores, and paper figures. PRISM source data must be downloaded separately. Simulation caches are generated by the scripts and are not included.

## Getting started

Use R 4.5.1. From the repository root, restore the pinned R packages:

```sh
Rscript -e 'install.packages("renv"); renv::activate(); renv::restore()'
```

Run the tests from `code/`:

```sh
cd code
Rscript tests/run_all.R
```

The tests use synthetic data and require no dataset download or API key. They cover estimators, sampling designs, covariance estimation and CV debiasing, taxonomy smoothing, and the simulation driver.

## Reproducing the results

1. **Prepare the data.** Follow the [setup and data instructions](details.md#setup). Python 3.14 is used for ingestion; the benchmark matrices and judge scores are included.
2. **Run the simulations.** From `code/`, run `paper_smoothing.R`, `paper_informative.R`, `paper_selection.R`, and `paper_single_sample.R` for the corresponding analyses. These write result caches to `data/`.
3. **Generate figures and tables.** Run the `paper_figures_*.R` and `paper_tables_*.R` scripts after their required simulations. See the [script-to-output map](details.md#reproducing-the-paper) for dependencies and commands.

Script headers describe numbered steps and available settings. See [shorter runs](details.md#shorter-runs) before starting a full simulation. Saved judge scores are sufficient for reproduction; rerunning the judge through an API is optional.

## Layout

All scripts run from `code/`, reading and writing through `../data` and `../paper`.

| Path | Contents |
|---|---|
| `code/R/` | Estimators and validation: populations and domains, designs, direct/PPI/GREG, Fay–Herriot and taxonomy smoothing, scoring, design-based cross-validation. `run.R` sources the rest. |
| `code/prism/`, `code/judge/` | PRISM ingest, population loader, judge prompts and runner. |
| `code/ollb/`, `code/mixedbench/` | Open LLM Leaderboard ingest and benchmark population loader. |
| `code/tests/` | Tests for estimators, sampling designs, covariance and CV, taxonomy smoothing, and the driver. |
| `code/paper_*.R` | Simulations (write caches to `data/`) and the figure and table scripts that read them. |
| `data/` | Judge prompts and scores; the benchmark matrices, zipped. |
| `paper/figures/` | The paper's four figures, and the taxonomy figure's TikZ source. |
